Add or replace a dataset

Upload a JSON file. Its name becomes the dataset name. Uploading the same name replaces that dataset.

You can also put a .json file in the datasets folder and refresh this page.

JSON format 
{
  "title": "Sample quiz",
  "subtitle": "Optional description",
  "questions": [
    {
      "id": 1,
      "title": "Question 1",
      "text": "Which statements are true?",
      "options": [
        {"id": "A", "text": "First statement"},
        {"id": "B", "text": "Second statement"}
      ],
      "correct": ["A"],
      "explanation": "A is true because..."
    }
  ]
}
